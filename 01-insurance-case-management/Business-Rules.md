# Business Rules

## Case Creation

- A case can be created only when the required policyholder and servicing information is available.
- Mandatory fields must be validated before case submission.
- Each successfully created case should have a unique reference number.

## Case Assignment

- Cases should be assigned based on configured business rules such as request type, servicing category or responsible team.
- A case should have an identifiable owner while it is in progress.
- Assignment changes should be traceable.

## Case Processing

- A case should move through defined statuses based on the completion of applicable activities.
- Required information should be available before the case moves to the next stage.

## Approval & Escalation

- Cases requiring approval should follow the configured approval workflow.
- Cases exceeding the defined turnaround requirement should be identified for escalation.

## Case Closure

- A case should not be closed until the required servicing activity has been completed.
- Closure should capture the applicable resolution information.
